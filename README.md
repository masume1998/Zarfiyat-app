# ظرفیت — نسخه کامل (Personal Financial Decision Assistant)

این نسخه دقیقاً بر اساس فهرست MVP خودِ سندت ساخته شده (بخش ۳۴):

✅ Onboarding کامل (اسم → منابع درآمد → هزینه‌های ثابت → تکنیک بودجه → سقف اقساط → تعهدات فعلی)
✅ چند منبع درآمد با تفکیک «قابل‌اتکا» و «متغیر»
✅ هزینه‌های ثابت دسته‌بندی‌شده
✅ ۶ تکنیک بودجه‌بندی، همه قابل شخصی‌سازی درصدی
✅ سقف اقساط با آستانه‌های 🟢🟡🔴 قابل تنظیم
✅ **موتور واقعی زمان‌بندی پرداخت (Payment Schedule Engine)** روی تقویم شمسی واقعی —
   نه فقط «مبلغ ÷ تعداد قسط»، بلکه بر اساس قانون هر سرویس:
   - اسنپ‌پی → ابتدای ماه بعد
   - دیجی‌پی → ماهانه، روز ثابت
   - تارا → هر ۳۰ روز
   - وام بانکی → ماهانه، روز ثابت
   - سایر → فاصله سفارشی (روز دلخواه)
✅ داشبورد (درآمد قابل‌اتکا/متغیر، هزینه ثابت، سقف، ظرفیت باقی‌مانده، وضعیت)
✅ Future Timeline بر اساس تاریخ واقعی هر قسط
✅ Purchase Simulator با تاریخ خرید، سرویس، و تشخیص «پرفشارترین ماه» (نه فقط همین ماه)
✅ برچسب «ضرورت خرید» کاملاً جدا از سطح ریسک مالی
✅ Calendar ماهانه با سررسیدهای واقعی
✅ Cash Flow (درآمد → هزینه ثابت → اقساط → پس‌انداز → پول آزاد)
✅ Financial Commitments عمومی (نه فقط BNPL: وام، قرض، کارت اعتباری، چک، بدهی شخصی)
✅ همه‌چیز در `localStorage` ذخیره می‌شود

## تعمداً هنوز اضافه نشده (طبق فاز‌بندی خودِ سند، بخش ۳۴)

اینها را عمداً برای فاز بعد نگه داشتم تا اول این نسخه رو تأیید کنی:
- Financial Health Score
- Goals (اهداف مالی + اثر خرید روی رسیدن به هدف)
- Smart Notifications
- سناریوسازی مقایسه‌ای (۴ قسط در مقابل ۶ قسط در مقابل نقد، پهلو به پهلو)
- Best Purchase Timing
- App Lock / Face ID / Hide Balance

هروقت گفتی «درستش کن»، می‌ریم سراغ رفع باگ‌ها و ریفاینمنت چیزی که ساختیم؛ هروقت گفتی
«تکمیل‌ترش کن»، از همین لیست بالا ادامه می‌دیم.

## نصب (همون روش قبلی)

فایل‌های این پوشه رو مثل قبل با Safari تو github.com آپلود کن (Add file → Upload files)،
GitHub Pages رو فعال کن، بعد از Safari آیفون با Add to Home Screen نصبش کن.
