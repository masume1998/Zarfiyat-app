# ظرفیت — دور دوم اصلاحات

## باگ‌ها که رفع شد
- **روزهای تاریخ نمی‌اومدن**: علتش تداخل id بین فرم Onboarding و فرم تعهدات بود
  (چون هر دو از یه فرم مشترک ساخته می‌شن). حالا هر فرم به خودش محدود شده.
- **سواپ کار نمی‌کرد**: الان علاوه بر سواپ، یه ضربه‌ی ساده هم قسط رو تیک می‌زنه —
  دیگه به کارکردن ژست touch وابسته نیست.
- **تارا اشتباه بود**: از «هر ۳۰ روز» به «ماهانه، روز ثابت» اصلاح شد.
- **ترتیب لیست در Onboarding**: تعهد جدید حالا بالای لیست میاد، نه پایین.

## ویژگی‌های جدید
- **Carousel صفحه اصلی**: کارت ظرفیت رو به چپ/راست بکش تا ظرفیت ۶ ماه آینده رو
  ببینی، هر ماه گیج و وضعیت خودش رو داره.
- **چک چند ماهه موقع افزودن تعهد مستقیم**: اگه از تب «تعهدات» (نه فقط Simulator)
  یه تعهد اضافه کنی که یکی از ماه‌های آینده رو پرفشار می‌کنه، یه هشدار می‌بینی.
- **پس‌انداز واقعی**: تو برنامه > جریان نقدی، می‌تونی بگی پس‌انداز این ماه رو کامل
  نگه داشتی یا بخشیش خرج شده و چقدر واقعاً مونده.
- **اسم خرید تو Simulator**: قبل از نهایی‌کردن، اسم خرید رو هم می‌پرسه.
- **پیش‌پرداخت آنلاین مشخص می‌شه**: تو نتیجه‌ی Simulator، قسط اول آنلاین با برچسب
  «پیش‌پرداخت، همین الان» جداست.
- **مبلغ کل یا فقط مبلغ قسط**: تو فرم تعهد، هر کدوم از این دو رو پر کنی، اون یکی
  خودش حساب می‌شه — برای وقتی که کل مبلغ رو یادت نیست.
- **سود/کارمزد وام**: برای وام و قرض یه فیلد «سود/کارمزد» اضافه شد که به کل بدهی
  اضافه و روی اقساط پخش می‌شه؛ برای این نوع‌ها گزینه‌ی آنلاین/حضوری هم دیگه نشون
  داده نمی‌شه چون معنی نداره.
- **هزینه‌های ثابت با دوره متفاوت**: حالا هر هزینه یه «دوره پرداخت» داره (ماهانه /
  هر ۳ ماه / هر ۶ ماه / سالانه) — برای مثل اشتراک سه‌ماهه یا بیمه‌ی سالانه.

## نصب
همون روش قبلی: این ۷ فایل رو (`index.html`, `manifest.json`, `service-worker.js`
و ۴ آیکون) جایگزین فایل‌های قبلی تو همون ریپازیتوری گیت‌هاب کن. داده‌هات دست‌نخورده
می‌مونه چون آدرس عوض نمی‌شه.
