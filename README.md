# ظرفیت — دور سوم اصلاحات

## این دور چی اضافه/درست شد

**پلتفرم، زمان‌بندی، و سود/کارمزد از هم جدا شدن**
قبلاً انتخاب پلتفرم (اسنپ‌پی/دیجی‌پی/تارا/...) خودکار نوع زمان‌بندی رو تعیین می‌کرد.
الان این دوتا کاملاً جدان: پلتفرم رو انتخاب می‌کنی (فقط برای شناسایی)، بعد جدا
مشخص می‌کنی زمان‌بندی واقعیش چیه (چون دو خرید از یه پلتفرم می‌تونن قانون متفاوت
داشته باشن). فیلد سود/کارمزد هم برای همه‌ی انواع تعهد (نه فقط وام) در دسترسه.

**ظرفیت ماه = کل اقساط اون ماه، نه فقط پرداخت‌نشده‌ها**
قبلاً وقتی یه قسط رو تیک می‌زدی، از محاسبه‌ی ظرفیت اون ماه حذف می‌شد. الان تیک
زدن فقط یه چک‌لیسته؛ ظرفیت مصرف‌شده‌ی هر ماه همیشه شامل کل چیزیه که اون ماه بودجه‌ش
رفته، چه پرداختش رو ثبت کرده باشی چه نه.

**تعهدات قابل مرتب‌سازی**
یه dropdown بالای لیست تعهدات اضافه شد: «نزدیک‌ترین سررسید» (پیش‌فرض) یا «آخرین
اضافه‌شده». همچنین یه فلش (chevron) کنار هر کارت هست که وقتی باز/بسته می‌کنی
می‌چرخه — تا معلوم باشه قابل بازشدنه.

**تیک زدن از صفحه‌ی خانه هم ممکنه**
بنر «اقساط نزدیک» تو صفحه‌ی اصلی الان دقیقاً مثل لیست تعهدات، با سواپ یا ضربه
تیک می‌خوره — لازم نیست حتماً بری تو تب تعهدات.

**رعایت جهت RTL**
فلش‌های برگشت (دکمه‌ی بازگشت تو فرم‌ها) که قبلاً به چپ اشاره می‌کردن (استاندارد
LTR)، الان به راست اشاره می‌کنن — جهت درست برای برگشت تو یه اپ راست‌به‌چپ.

## یه محدودیت فنی صادقانه

خواسته بودی کیبورد خودش بین فارسی/انگلیسی سوییچ کنه. فیلدهای مبلغ همین الانشم
کیبورد عددی می‌ندازن بالا (که مستقل از زبانه، مشکلی نداره). اما برای سوییچ کامل
بین کیبورد فارسی و انگلیسی برای فیلدهای متنی، این چیزی نیست که یه صفحه‌ی وب
بتونه کاملاً کنترلش کنه — زبان کیبورد رو خود iOS و کیبوردهای نصب‌شده‌ی کاربر
تعیین می‌کنن، نه سایت. چون تو این اپ عملاً فیلد متنی‌ای نداریم که نیاز به
انگلیسی داشته باشه (همه‌چیز یا فارسیه یا عدد)، فکر می‌کنم فعلاً نیازی بهش نیست؛
اگه جایی خاص مدنظرته بگو دقیق‌تر بررسی کنم.

## هنوز برای فاز بعد (طبق خواسته‌ی خودت)

الگوی Bingers (سواپ چپ = تیک/پرداخت‌شده، سواپ راست = رد کردن/skip، نمایش شبیه
«قسمت بعدی») — منتظر می‌مونم بگی چطور می‌خوای این بازطراحی رو انجام بدیم.
